# HUST Robotics Engineering Portfolio

Welcome! I am a freshman majoring in Robotics Engineering at Huazhong University of Science and Technology (HUST). This repository serves as my personal workspace to document my learning journey, coding practices, and hardware projects.

## 📂 Repository Structure

Here is an overview of the different modules in this repository:

### 🚁 ThinkFly
This directory contains projects and code related to **drone simulation development**. It aims to explore flight dynamics, control algorithms, and simulation environments for unmanned aerial vehicles (UAVs).

### 💻 practice
A collection of my **daily C++ practice** and algorithmic exercises. This folder contains various course assignments, problem-solving scripts (like ThinkFly problem sets), and fundamental coding experiments to build a solid programming foundation.

### 🔌 arduino
Embedded systems development projects targeting **ESP32 and STM32** microcontrollers. This includes hardware initialization, peripheral control, and sensor integration using C/C++.

## 🛠️ Tech Stack & Tools
*   **Languages:** C++, Python
*   **Hardware:** ESP32, STM32
*   **Tools:** Git, GitHub Desktop, VS Code, Arduino IDE

## 🎯 Future Goals
As a robotics engineering student, my goal is to bridge the gap between software algorithms and physical hardware. I will continue to update this repository as I learn more about ROS (Robot Operating System), computer vision, and robot control.
